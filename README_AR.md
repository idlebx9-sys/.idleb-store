# IDLEB STORE — النسخة المطوّرة

هذه النسخة تحتوي على متجر IDLEB STORE بواجهة عربية RTL، كتالوج خدمات، سلة، محفظة، حسابات العملاء، متابعة الطلبات، ولوحة إدارة تشغيلية كاملة.

## أهم التحسينات

- مركز طلبات إداري عمودي وواضح، مع فتح سجل الطلب كاملًا.
- عرض رابط الحساب المستهدف، المنصة، اسم المستخدم أو المعرّف، الملاحظات، بيانات التواصل، الدفع، والمبلغ.
- زر نسخ رابط الحساب مباشرة من تفاصيل الطلب.
- بحث وتصفية حسب حالة الطلب ونوع الخدمة.
- تحديث حالات الطلبات مع حفظها بعد إعادة تحميل الصفحة.
- مؤشرات الإيرادات، عدد الطلبات، الطلبات المعلقة، والعملاء.
- إدارة الخدمات والأقسام والعملاء وطلبات الشحن والشكاوى وإعدادات المتجر.
- تسجيل الحساب مرتبط بـ EmailJS مع OTP من 6 أرقام، إعادة إرسال، وانتهاء صلاحية بعد 10 دقائق.
- لكل خدمة تعليمات وحقول طلب خاصة بها، مع منع طلب كلمات المرور أو رموز التحقق.
- خلفية فيديو متجاوبة ومعتّمة؛ غيّر الرابط من الثابت `BACKGROUND_VIDEO_URL` في `src/App.tsx`.
- تصميم Black / White / Dark Crimson Responsive مع نسخة الفيديو في `public/store-background.mp4`.

## دخول لوحة الإدارة

- اسم المستخدم: `admin`
- كلمة المرور الافتراضية الحالية: `Idleb@2025`

> هذه النسخة تحافظ على بنية المشروع الأصلية وتستخدم `localStorage` كما كانت. EmailJS يرسل رمز التحقق من الواجهة، لذلك يجب نقل المصادقة وصلاحيات الإدارة إلى Backend/Database قبل الاستخدام التجاري؛ لا تعتبر localStorage نظام صلاحيات أو قاعدة بيانات آمنة.

## تشغيل نسخة الموقع الجاهزة

افتح مجلد `site` واستضف محتوياته على أي استضافة ملفات ثابتة. الملف `site/index.html` هو نقطة البداية.

## تشغيل نسخة المصدر

المجلد `source` هو كود React/Vite الكامل للواجهة. من جذر مشروع pnpm شغّل:

```bash
pnpm install
pnpm --filter @workspace/idleb-store run dev
```
## مزامنة الإدارة لجميع الأجهزة
لوحة الإدارة الآن تزامن الأقسام والخدمات والصور وإعدادات المتجر عبر Cloudflare KV. يجب إنشاء KV namespace وربط ID الخاص به في `wrangler.jsonc` قبل النشر النهائي.
